# TerraNova — Android APK Build Project 0.2

هذا المشروع مُجهّز ليكون نقطة البداية لإخراج APK قابل للتثبيت.

## المطلوب لإخراج APK
1. افتح المجلد في Android Studio.
2. انتظر Gradle Sync.
3. من القائمة: Build → Build APK(s).
4. ستجد APK التجريبي في:
   app/build/outputs/apk/debug/app-debug.apk

## مهم
هذا الملف هو **مشروع البناء** وليس APK نفسه. بيئة المحادثة هنا لا تحتوي على Android SDK/Gradle الكامل، لذلك لا يمكنني ادعاء أن APK تم بناؤه فعليًا.

# TerraNova 0.7 — Parallel Projects

## Project A — Civilization Progression
- 5 civilization levels.
- Slow score-based advancement.
- Each level depends on ecosystem, climate, research, population and discovered regions.

## Project B — Technology Tree
- Water Engineering
- Energy Storage
- Environmental Engineering
- Life Sciences
- City Planning
- Planetary Network

Technologies require research and prerequisites, preventing rapid progression.

## Project C — Achievements and Rewards
- Water milestone
- Healthy ecosystem
- Stable climate
- Researcher milestone
- First life project
- City builder

Achievements grant one-time rewards.

## Project D — Next Parallel Systems
1. Resource economy balancing.
2. Regional map with different resource profiles.
3. Random planetary events.
4. Expanded life-lab progression.
5. Save/migration compatibility.

The rule for all projects: slower progression, meaningful decisions, and no single action should unlock the whole game.
